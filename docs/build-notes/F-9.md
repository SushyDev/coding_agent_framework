# F-9: moving a parent, corrected from Move.tla (design)

## What was built

Design only, no code. `docs/design.md` takes F-5's findings, with the owner's decisions:

- A move starts on its own when the account reaches 90 % of its weekly allowance, or with a
  press at any level (F-5 new-4).
- The steps wait until no background command runs, after the drain began (new-1).
- The session is ended through `Control`'s checked write, `/exit` only when the turn has ended
  and the input box is empty (new-5).
- The transcript is copied after the old process exits, then the session resumes (new-2).
- Running delegates do not hold a move; a report is held until a parent process runs, and
  `Delegate.tla`'s invariants say so (new-3).

`Move.tla` already models these steps.
