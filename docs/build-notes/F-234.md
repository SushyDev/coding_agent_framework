# F-234: the tree names each session's transcript and each subagent's id

## What was built

- Each agent row of `Tracker.Tree.agents/2` carries `transcript`: the path in the session's
  transcripts row, or nil when there is none (a session not started, a headless agent before its
  first `init`). It is never built from the cwd.
- Each subagent carries `agent_id`, as the transcripts' fold holds it.
- The MCP `agents` tool passes both through (the tree is returned whole); its description names
  them.
- A tree test: a started session names its transcript, one before its start names nil, a
  subagent names its `agent_id`. `docs/design.md` and the README status line say so.

Nothing beyond the gates.

## What I ran into

Nothing: the rows already held both values; the view dropped them.
