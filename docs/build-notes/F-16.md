# F-16: the delegate protocol, from Delegate.tla and Accounts (design)

## What was built

Design only, no code. `docs/design.md` takes the findings of F-14 and F-15:

- Step 5: the row leaves running once, by the Stop event or the transcript's last reply; a report
  is tried at each of the parent's turn ends and held again when refused; a sending mark before
  the write, settled from the parent's transcript after a restart (F-14 new-1, new-2, new-4).
- Step 6: a kill before the last reply is resumed once, a second one is reported on the path of a
  finish, and a kill after the last reply is a finish (F-14 new-3).
- A start writes its row first and is adopted or ended after a restart (F-14 new-5).
- Accounts: a person logs each account in; the framework never reads a credential, so login is
  unknown until a session starts (F-15 new-2). It writes only its own files, named by flag, and
  through `Shell` on a remote host (F-15 new-3). A delegate's Remote Control is off by a setting,
  checked against each pinned release (F-15 new-1).
