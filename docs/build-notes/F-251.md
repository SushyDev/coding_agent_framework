# F-251: a test lists only the stand-in's session files

## What was built

`tree_main_test.exs` asserted that the stand-in's sessions folder held exactly one entry. The
stand-in writes each change to its session file through `<pid>.json.tmp`, then renames it, so a
listing taken during a status change sees both. The test now lists only `*.json`. Nothing else
changed.

## What was measured

In a `devenv test` run on 2026-11-24, the assertion failed once with `{:ok, ["60624.json",
"60624.json.tmp"]}`. The same test passed in the three `gate-test` runs that followed.

## Findings

None.
