# F-288: db_connection 2.10.3, past a security advisory

## What was built

`mix.lock` moves db_connection from 2.10.2 to 2.10.3 (and telemetry from 1.4.2 to 1.4.3, which
came with it). `mix hex.audit` failed on 2.10.2 with EEF-CVE-2026-133555 (CVE-2026-133555,
GHSA-gmmq-fw75-wq46): code execution through the `:log` option of a forged `DBConnection.Stream`.
The framework reaches db_connection through ecto_sqlite3. After the update `mix hex.audit` finds
no retired package and no advisory.

## What was measured

A forced compile in dev and test, with warnings as errors, and the tests of the apps that use the
store most (`caf_store`, `caf_acts`, `caf_mailbox`) all passed.

## Findings

### new-1. The gates do not run `mix hex.audit`

The advisory was found by another project's audit, not by this repository's gates. Adding
`mix hex.audit` to `gate-test` would catch the next one on any branch. It needs Hex's network,
so it may belong in a gate of its own that can fail on a network error without failing the code.
