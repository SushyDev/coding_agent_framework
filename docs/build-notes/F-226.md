# F-226: setup refuses without a terminal; the console sets its own aliases

## What was built

- `bin/caf-login --setup` refuses before its first step, with status 2, when stdin or stdout is
  not a terminal: a browser login and Claude Code's onboarding would otherwise wait forever
  (F-220's new-2). The tests set `CAF_LOGIN_NO_TTY_CHECK`, since their stand-ins need no
  terminal. A test runs `--setup` with the check on and no terminal: refused, no step run.
- The example console's `console.iex.exs` sets the aliases the end-to-end run uses beside the
  console's calls (`Logins`, `Agents`, `Run`). On 2026-11-23 a console started again after a
  restart had lost them, and `Run.parts/1` was undefined. `docs/e2e.md` steps 1 and 8 say so.
