# F-6: decisions on F-2's and F-3's findings (design)

## What was built

Design only, no code. `docs/design.md` takes these decisions:

- The state rules are checked as property tests over generated event sequences. No spec models
  the `Tracker`'s fold, which is a pure function; one is written when a bug shows an order of
  events needs it.
- A held process's environment is built from nothing (`env -i` and an explicit list of what it
  keeps), the same locally and over ssh (F-2 new-3).
- A held agent's pid comes from its session file, which `Registry` reads; `Holder` no longer
  hangs up or lists a socket's children (F-2 new-4).
- Every tmux command on a kept pane id goes through the one-command check, and a send's text and
  Enter go out in one command (F-3 new-1, new-3).
- Item 3 of the order notes that `Control` came first, as its own unit.

F-3 new-2 (a port can close before it reports its pid) needs no design change.
