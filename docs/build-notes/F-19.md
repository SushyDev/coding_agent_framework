# F-19: allowance and sessions, from Usage and Sessions (design)

## What was built

Design only, no code. `docs/design.md` gains an "Allowance" section and takes the findings of
F-17 and F-18, with the owner's decisions:

- A reading is current for 6 hours; an older one is unknown for `pick` and the move (F-18 new-2).
- A reading past its reset counts as 0 % used, marked as assumed (F-18 new-1).
- A check flags an account with no new reading after its sessions' first answer, and a remote
  host's file is read through `Shell` (F-18 new-3, new-4).
- `Screen` answers the workspace trust dialog at a start; settings never set `disableAllHooks`
  (F-18 new-3).
- A start is confirmed by the session file's `name`, checked per release (F-17 new-1).
- Adoption waits for the start's deadline, then keeps an orphan row for `Recoveries`; stopping
  rows are settled by pid after a restart, and unknown rows are read again (F-17 new-2, new-3).
- `Delegate.tla` gains the start before `Delegates` is built (F-17 new-4).
- A wait on a reader inside a call polls until the call's deadline; everything else follows the
  reader's cue (F-17 new-5).
