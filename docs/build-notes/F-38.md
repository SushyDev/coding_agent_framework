# F-38: agents working together, from Team.tla (design)

## What was built

Design only, no code. "Agents working together" takes F-29's findings:

- A message has a report's sending mark and settle, and goes on to a parent only from a settled
  row (new-1, new-2).
- Order is per sender and addressee (new-3).
- Claims are rows in `Grants`' table; a claim a restart cut off is closed as interrupted (new-4).
- A fix acts only while the claimed state is still current (new-5).
- `keep: true` hands a service to the owner's parent when the owner ends; `service_hand` hands
  one to another agent (new-6).
- A message is refused only for a name the project does not hold, and waits for a dead agent
  (new-7).
- A call ends verified or not, and a fix that did not help goes to a person (new-8).
- `look` and `interrupt` name what they do for a headless delegate (F-30).
