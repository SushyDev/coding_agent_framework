# F-33: headless delegates, from Stream.tla (design)

## What was built

Design only, no code. `docs/design.md` takes F-31's findings:

- A message that joins a turn the delegate started by itself is accepted and still delivered
  once, by its replay (new-2).
- A claim starts only for a live delegate, under the write's deadline, and `Recoveries` ends a
  claim command still waiting past it, by pid and start time (new-3).
- `Programs` names `mkfifo` for the wrapper's pipe (new-1).
- `Usage` reads each delegate's latest `rate_limit_event`; the internal field is in the
  per-release check (new-4).
- An undelivered message goes to the resumed process under its same uuid, which Claude Code
  drops if its transcript already holds it (new-5).
- A held stdin permission request has no deadline of its own; a view flags one held longer than
  10 minutes (new-6).
