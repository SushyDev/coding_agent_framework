# F-219: the MCP tools offer the effort levels as an enum

## What was built

- `MCP.start_link/1` takes `efforts:`, a required non-empty list of strings. A missing or empty
  list, or one with anything but strings, is refused `{:bad, :efforts}`, as its other options are.
- The `effort` property of `start_delegate` and `run_delegate` is now
  `%{type: "string", enum: efforts, description: …}`. The description says what an effort is and
  no longer lists the levels.
- The surface passes `ClaudeCLI.efforts/0`, and no other app copies the list. `caf_mcp` gains
  no dependency on `caf_cli`.
- `Delegates` keeps its own check and its refusal `{:effort, value}`.
- Tests: the listed schema carries the enum equal to the list given; `efforts:` is required and
  must be a list of strings, never empty; the surface's tools carry `ClaudeCLI.efforts/0`.

## What was measured

Nothing new: this is a tool's schema, not a protocol, so no model changed.
