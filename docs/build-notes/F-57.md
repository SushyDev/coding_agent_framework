# F-57: `Sessions.Worktree`, the pure checks of a start's worktree

## What was built

The first half of F-55's code, split as F-55 new-11 proposes. F-55's builder wrote it; the
reviewer split it off unchanged. `CodingAgentFramework.Sessions.Worktree` is a pure module over
what git prints ("The worktree" in `docs/design.md`; `model/tla/Start.tla`'s `Checked`, `Added`
and `Remove`):

- `project/1` checks a project's data, `%{name, repo, trunk, setup, setup_timeout, env}`, with
  every program and the repository absolute;
- `branch/1` takes only a plain ref name, so a branch is never read as an option or a revision;
- `path/3` and `name?/1`: a session's worktree is `<root>/<project>/<name>`;
- `env_args/1` and `git/2`: the `env -i` arguments and git's argv;
- `listed/2` reads `git worktree list --porcelain -z`;
- `decide/4` (`Checked`) and `removal/4` (`Remove`).

Nothing calls it yet. F-58 wires it into `Sessions`.
