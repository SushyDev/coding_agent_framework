# F-56: ending the stand-ins of a test that started none

## What was built

`ClaudeStandIn.kill_all/1` and `HeadlessStandIn.kill_all/1` listed `<dir>/pids` with
`File.ls!/1`, which raises when no stand-in ever made the directory. `SessionsSetup` runs both on
every test's exit, so a test that started no stand-in of one kind raised in its `on_exit`
(F-52 new-3). Both now treat a missing `pids` directory as nothing to end. Any other error still
raises, since a directory that cannot be read may hold pids to end.

`apps/caf_test/test/stand_in_test.exs` checks both on a test directory with no stand-in.
