# F-27: remote hooks, host-wide readers and the sampler (design)

## What was built

Design only, no code. `docs/design.md` takes the owner's decision on remote hooks and the open
findings of F-22 and F-24:

- A remote host's hooks reach `Intake` through a reverse forward on the framework's one ssh
  connection to that host; while it is down, events are lost as during a restart (F-24 new-3,
  owner's decision).
- A pane's key includes its server's start (F-22).
- A reader of a whole host has the `Tracker` scope `{host, :host}` (F-22 new-1).
- A source answers its rows and its problems together (F-22 new-2).
- A recovery acts on a lost viewer only when two samples in a row agree, since the sampler's two
  reads are not one instant (F-22 new-3).
- Untagged and mis-tagged panes are broken states the sampler reports (F-22 new-4).
- Duplicate Stop, Notification and SessionEnd rows are harmless, since no part counts them
  (F-24 new-4).

Left for later units: `Agent.tla`'s header naming `TmuxSampler` as built (F-22 new-5), once the
unit changing `Agent.tla` lands; and the code changes these imply for the `Tracker`'s scope, the
source behavior and `Recoveries`.
