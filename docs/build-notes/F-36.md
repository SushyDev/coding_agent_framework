# F-36: an umbrella, one app per part (design)

## What was built

Design only, no code. The owner decided the framework is composed of single-purpose umbrella
apps, one per part. "The parts" says how: `apps/` with one OTP app per part, each declaring only
the apps it uses so the layers are enforced at compile time, shared test aids in `caf_test`,
module names unchanged, and the model, devenv, design and gates at the root.

The move itself is the next unit: mechanical, the same modules and tests in their apps, no
change of behavior, after the units changing `lib/` have landed.
